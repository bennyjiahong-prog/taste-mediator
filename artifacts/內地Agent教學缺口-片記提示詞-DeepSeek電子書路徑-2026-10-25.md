### 1.2 外語市場相對薄的機制

下列是機制，不是播放量比較。【推測】，除非另標。

1. **語言與成品形態不同。** 簡體長片平台獎賞「從零到發布」的一小時以上口播。英語的同等知識常常拆在論文、大學投影片、框架文件和十來分鐘短課。知識不一定少，可購買的「繁體、逐步、今晚跑得起來」少。
2. **監管與產品詞彙不能對譯。** 扣子、飛書、企業微信、釘釘、星辰一類平台，加上內地模型接口與內容合規詞彙，構成一套辦公現場。英語教程教的是 LangGraph、MCP、Claude、Slack。把一邊的按鈕翻譯到另一邊，讀者照做會失敗。這是真缺口，也是最容易整段搬運的缺口。
3. **開源生態把英語深度放在倉庫，不放在課堂。** ReAct 這類骨架在英語側先以論文和文件存在；Hugging Face 把練習放進筆記本。內地則把同一骨架講成平台課。會讀文件的人覺得英語不薄；不讀文件、要看片照做的人覺得薄。
4. **某些地區是雙重隔閡，不是單邊落後。** 香港讀者可能讀得懂英語短課，卻用不上內地平台帳號；也讀得懂簡體長片，卻不能把火山引擎或電信平台的步驟原樣搬進自己的環境。【推測】未做港企工具採用率調查。【未驗證】
5. **搬運把「外國沒有」這個印象放大了。** 伯克利官方站有錄影；b 站同時有中文標題的搬運。觀衆先看到中字長片，就會以為深度只存在於內地。對 Ben 而言，這類片是反面教材：未授權翻譯加鏡像，正是第 4 類紅線。

### 1.3 八個子題

每個子題都給：內地常見講法、英語側實際在哪裡薄、本席判斷。不附假播放量，不附未核實的教授姓名。

**1. 工具調用、函數調用、ReAct**

- 內地：平台課把「插件／工具」講成扣子或 Dify 的按鈕；b 站長片會演示函數調用。中傳特訓營頁面把 Function Call 列為課程目標。【已驗證：搜尋摘錄】只及於該頁的列項，未看片。
- 英語：Stanford 大綱有工具調用與 ReAct；DeepLearning.AI 短課教「模型與外圍程式如何分工」；Hugging Face 筆記本有 tool calling。【已驗證：搜尋摘錄】
- 薄在哪裡：薄的是繁體、不綁某一框架商標的「一次呼叫失敗了怎麼讀日誌」。【推測】概念本身不薄。
- 出售判斷：宜作書中的一章，不宜整本書只講 ReAct。論文與短課都在，跟單一來源的結構重合風險高。

**2. 多智能體協作**

- 內地：b 站長片常以「多 Agent、分工、群聊」作標題。本次沒有核對某一門大學課的完整實驗設計。【未驗證】具體哪一門最詳。
- 英語：伯克利 2025 秋季大綱有多智能體專講（官方頁列出客座講者與錄影連結）。【已驗證：搜尋摘錄】
- 薄在哪裡：可重做的小型實驗少，名詞演示多。框架一個月一改，書會快過期。【推測】
- 出售判斷：暫緩當主打。可在本地智能體跑通之後，加一章「兩個角色、一張交接單」。

**3. 本地智能體加 Ollama、以及支援工具調用的本地模型**

- 內地：2026 年 b 站搜尋結果大量出現「本地部署、接入飛書或企業微信、Ollama」的長片，標題常同時寫 OpenClaw 與 Clawdbot。【已驗證：搜尋摘錄】只證實題材密集，不證實任何一條片準確、穩定或允許再製。
- 英語：Ollama 官方文件、零散 YouTube、以及華語講者上傳的英文站影片都有。本次抽樣沒有看見與內地長片同等密度的英語大學實驗課。【未驗證】全站；【推測】密度較低。
- 薄在哪裡：繁體、寫明模型必須支援工具調用、寫明失敗日誌、而且步驟來自作者自己的機器，而不是某一條「保姆級」片。
- 出售判斷：八題裡最適合先試。正文可以改為對照 Ollama 官方文件加 Ben 的運行記錄。內地片只用來發現「讀者會卡在哪一步」。

**4. 企業微信、飛書、扣子一類辦公現場智能體**

- 內地：最充裕。扣子平台課有完整節次；b 站長片把飛書、企業微信、釘釘接進本地程式。YouTube 上亦見華語講者的同類片，所以不是「英文站點零供應」。【已驗證：搜尋摘錄】
- 英語：英文講者的逐步課堂少，因為產品不在英語辦公預設裡。【推測】
- 薄在哪裡：這是地區缺口，不是全球知識缺口。香港是否用同一套介面，本席沒有核。【未驗證】國際版 Lark 與內地飛書的差異，要 Ben 自己點一次才算數。

- 內地：中傳頁與電信平台課都把知識庫／產業落地放進大綱；扣子課則偏工作流，不等於 RAG 專課。【已驗證：搜尋摘錄】

- 薄在哪裡：幾乎不薄。兩邊都擠。【推測】
- 出售判斷：可作「檢索失敗時智能體怎樣改查詢」的一節，不要當書名。

**6. 瀏覽器智能體**

- 內地：本次沒有核到一門大學課專講瀏覽器智能體。【未驗證】b 站是否有長片，只宜用第 2 節的搜尋詞去看，本席不報數目。

**7. 評測、失敗模式與最小護欄**

- 內地：本次抽到的平台課大綱偏搭建、發布、工作流。不能因此說內地沒有評測課。【未驗證】只是這次抽樣的平台課不以此為主。

- 薄在哪裡：給「已經能跑一個智能體的人」的繁體實驗：怎樣準備十條固定問題、怎樣記錄工具叫錯、怎樣設一條拒絕越權的規則、怎樣承認評測不是認證。【推測】
